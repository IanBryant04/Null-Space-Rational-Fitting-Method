# Null-Space Rational Fitting

Python implementations of rational-fitting methods for real and complex
data, with applications to GDP modeling and RF S-parameter analysis.

A rational approximation represents a function as a ratio of polynomials.
This project explores a null-space fitting approach and includes
comparison code for vector fitting.

## Implementation

The code includes the null-space fitting method, a comparison with
vector fitting, and an application to RF S-parameter data.
An example dataset is included.

## Getting oriented

Start with `NullSpaceMethod.py` for the fitting implementation.
The comparison and S-parameter scripts show related applications.

## Scope

This repository is a proof of concept for exploring fitting methods.
The examples cover real-valued data and complex-valued RF responses.
